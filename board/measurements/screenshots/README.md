# 测量截图

本目录保存上板测试和 Vivado 结果截图。

| 文件名 | 内容 |
| --- | --- |
| `uart-terminal.png` | 串口终端输出；有效帧 7497，校验错误 0，序号跳变 0，运行 60.13 秒 |
| `vivado-simulation.png` | `tb_basys3_arm_final_top` 行为仿真波形 |
| `vivado-timing.png` | 时序汇总；WNS +1.048 ns，WHS +0.065 ns，失败端点 0 |
| `vivado-utilization1.png` | Slice LUT 和 Slice Register 使用情况 |
| `vivado-utilization2.png` | Block RAM 和 DSP 使用情况 |

本目录没有示波器或逻辑分析仪拍摄的舵机 PWM 截图。
