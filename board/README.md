# 上板工程与实测材料

## 文件

- `basys3_arm_final_top.bit`：已验证 bitstream。
- `SHA256SUMS.txt`：bitstream 校验值。
- `program.tcl`：通过 Vivado Hardware Manager 下载 bitstream。
- `constraints/basys3_arm_final.xdc`：引脚、时钟和 IO 约束。
- `pinmap.csv`：Basys 3 引脚与外部模块对应关系。
- `wiring.md`：供电、接线和上电顺序。
- `software/`：UART 遥测读取与 CSV 记录脚本。
- `measurements/board-validation.csv`：板级测试记录。
- `measurements/quantitative-results.csv`：量化测量记录模板。
- `photos/`：实板照片。
