# 测试计划

## 1. 测试目标

验证三路传感器、FPGA 处理和三路舵机组成的完整控制链，包括：

- 肌电采集、基线校准和机械手开合。
- 弯曲传感器阈值、滞回、点动和限位停止。
- MPU6050 I2C 通信、GY 轴选择、方向确认和底座控制。
- UART 遥测、LED 状态和七段数码管。
- Vivado 仿真、综合、实现、时序和 DRC。

## 2. 环境

| 项目 | 配置 |
| --- | --- |
| 开发板 | Digilent Basys 3 |
| FPGA | XC7A35T-1CPG236C |
| Vivado | 2025.1 |
| 肌电前端 | MyoWare 2.0 ENV |
| ADC | Pmod AD1 |
| 姿态传感器 | GY-521 / MPU6050 |
| 舵机 | 3 个 180° 位置舵机 |
| 串口 | 115200 8N1 |
