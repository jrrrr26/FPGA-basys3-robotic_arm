# 上板测试与测量方法

本文用于填写 `board/measurements/board-validation.csv`，并保证测试过程可重复。

## 1. 通用记录

每次测试先记录：

| 字段 | 示例 |
| --- | --- |
| 日期 | 2026-11-02 |
| bitstream SHA256 | `D489...56AA` |
| 板卡 | Basys 3 |
| 电源 | 独立 5 V 舵机电源 |
| 测试人 | 项目成员 A |
| 视频/截图 | 文件名或链接 |

所有测试开始前：

1. 检查三个舵机使用独立 5 V 电源并与 Basys 3 共地。
2. 上电后保持肌肉放松、手腕静止约 1.5 秒。
3. 确认 LED0 心跳、LED3 熄灭。
4. 确认串口输出正常。

## 2. 肌电机械手重复成功次数

### 测试方法

共做 10 次：

1. 保持肌肉放松 3 秒，确认 JC4 处于张开状态。
2. 主动紧绷约 2 秒，观察 JC4 是否开始闭合。
3. 保持紧绷，观察机械手是否到达闭合位置。
4. 恢复放松 3 秒，观察 JC4 是否回到张开位置。

### 判定标准

- 紧绷后 2 秒内开始闭合。
- 闭合方向正确，无明显反向动作。
- 放松后能够回到张开状态。

### 记录

```text
成功次数 = 10 次中满足标准的次数
成功率 = 成功次数 / 10 × 100%
```

## 3. 弯曲前臂重复成功次数

### 测试方法

高位和低位各做 10 次：

1. 将弯曲传感器保持在中间区，确认 JC3 不持续动作。
2. 快速弯曲到高值，保持约 1 秒，再回到中间区。
3. 观察 JC3 是否向 160° 方向点动，并在回中后停止。
4. 向相反方向弯到低值，保持约 1 秒，再回到中间区。
5. 观察 JC3 是否向 20° 方向点动，并在回中后停止。

### 判定标准

- 高值方向正确。
- 低值方向正确。
- 回到中间区后 0.5 秒内停止动作。
- 不出现持续抖动或越过安全限位。

### 记录

```text
高位成功次数 = 10 次中满足标准的次数
低位成功次数 = 10 次中满足标准的次数
```

## 4. 陀螺仪底座左右转和停止冻结

### 测试方法

左转、右转和停止各做 10 次：

1. 手腕静止，确认底座不动作。
2. 手腕向左转动约 1 秒，观察 JC1 是否向正确方向变化。
3. 停止转动手腕，观察底座是否立即停止并保持当前角度。
4. 手腕向右转动约 1 秒，观察 JC1 是否向反方向变化。
5. 如果接近 10° 或 170° 限位，反向转动回中间后继续测试。

### 判定标准

- 左右方向与 SW0 设置一致。
- 手腕停止后 0.5 秒内停止，不继续追赶旧目标。
- 不因普通平移或轻微晃动频繁触发。
- 不越过 10°～170° 控制范围。

### 记录

```text
左转成功次数 = 10 次中满足标准的次数
右转成功次数 = 10 次中满足标准的次数
停止冻结成功次数 = 10 次中满足标准的次数
```

## 5. 串口有效帧数、校验错误数和序号跳变

使用仓库自带脚本运行 60 秒：

```powershell
python board/software/read_arm_com.py --port COM9 --duration 60 --csv board/measurements/uart_60s.csv
```

脚本结束时会打印：

```text
有效帧 N，校验错误 M，序号跳变 K，运行 T 秒
```

将 N、M、K 和 T 填入 `board/measurements/board-validation.csv`。

### 判定标准

- 有效帧持续增加。
- 校验错误为 0。
- 没有因程序重启导致的序号大范围跳变。
- 若出现少量串口丢帧，应能通过 USB 线、电源或串口占用情况解释。

完整 CSV 可以另存，仓库只保留短时调试样本。

## 6. 连续运行时间

### 测试方法

至少运行 30 分钟：

1. 连接三个舵机和正常机械负载。
2. 每 2 分钟依次执行一次肌电、弯曲和陀螺仪动作。
3. 保持串口记录。
4. 观察是否出现异常复位、舵机失控、I2C 错误或通信中断。
5. 记录开始时间、结束时间、异常次数和最高舵机电源电流（如有电流表）。

### 判定标准

- 30 分钟内无异常复位。
- 无持续堵转、异常发热或明显电源跌落。
- 串口持续输出，I2C 错误不持续出现。
