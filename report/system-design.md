# 系统设计说明

## 1. 项目概述

本系统在 Basys 3 上实现从传感器采集到机械臂执行的一体化控制。FPGA 直接完成 ADC 读取、滑动平均、肌电状态判断、弯曲方向控制、MPU6050 I2C 读取、陀螺仪零偏校准、舵机 PWM 和 UART 遥测，不依赖电脑参与实时闭环。

## 2. 系统数据流

```text
MyoWare ENV -> Pmod AD1 A0 -> 64 ms 滑动平均
    -> 肌电基线校准 -> 放松/紧绷 -> JC4 机械手

弯曲传感器 -> Pmod AD1 A1 -> 64 ms 滑动平均
    -> 高低阈值与滞回 -> JC3 前臂

MPU6050 GY -> I2C 100 kHz -> 零偏校准与低通
    -> 120 ms 确认 -> 速度分级 -> JC1 底座

所有状态 -> LED、七段数码管、18 字节 UART
```

## 3. 控制策略

### 3.1 肌电机械手

- 上电后保持放松约 1.5 秒完成基线校准。
- 肌电滑动平均超过自适应门限后判定紧绷。
- JC4 目标角由 30° 逐渐移动到 150°，形成闭合动作。
- 肌电恢复放松后，目标角回到 30°。
- 使用 `angle_slew` 逐步改变角度，避免舵机瞬间跳变。

### 3.2 弯曲前臂

- 使用绝对阈值，不依赖伸直基线。
- 高值进入门限 3000，释放门限 2500。
- 低值进入门限 800，释放门限 1200。
- 高值向 160° 点动，低值向 20° 点动。
- 每 20 ms 改变 2°，中间区停止 PWM，保留最后角度。
- 到达 20° 或 160° 后停止 PWM，防止持续堵转。

### 3.3 陀螺仪底座

- 使用 MPU6050 的 GY 轴，而不是最初误选的 GZ 轴。
- 上电后保持手腕静止完成零偏校准。
- 采用 1/8 低通滤波，减少短时噪声。
- 连续 12 个样本同方向超过死区才确认动作。
- 慢速、中速、快速三档分别改变目标角。
- 回到死区后立即冻结目标，不追赶停止前的旧值。
- `SW0` 可反转方向，适配不同佩戴方向。
- 目标角限制在 10°～170°。

## 4. 主要模块

| 模块 | 作用 |
| --- | --- |
| `basys3_arm_final_top.v` | 最终系统顶层与三路控制集成 |
| `spi_adc.v` | Pmod AD1 双通道 12 位采样 |
| `window_average_unsigned.v` | 肌电与弯曲通道滑动平均 |
| `emg_state_classifier.v` | 肌电基线、门限与紧绷判断 |
| `flex_angle_mapper.v` | 弯曲阈值、滞回和 JC3 点动控制 |
| `mpu6050_six_axis_reader.v` | MPU6050 六轴寄存器突发读取 |
| `gyro_bias_calibrator.v` | GY 零偏校准与低通滤波 |
| `gyro_base_controller.v` | GY 方向确认、速度分级和目标角控制 |
| `angle_slew.v` | 底座和机械手角度平滑过渡 |
| `servo_pwm_pulse.v` | 50 Hz 舵机 PWM |
| `uart_single_frame_tx.v` | 18 字节遥测帧 |
| `seven_segment_raw_display.v` | 四位数码管显示 |

## 5. 设计取舍

- 使用 FPGA 片内逻辑完成实时处理，避免 USB 或操作系统调度抖动。
- 肌电使用自适应基线，适应不同佩戴状态。
- 弯曲使用绝对阈值和滞回，结构固定后不需要每次校准。
- 陀螺仪使用角速度而非加速度计，避免平移和重力方向变化直接误触发。
- 不使用三轴角速度矢量和，避免任何方向的晃动都驱动底座。
- 到达机械安全边界后关闭 PWM，降低舵机堵转和发热风险。

## 6. 已知边界

- 更换机械结构、舵机批次或电池电压后，需要重新确认角度和停止脉宽。
- 肌电阈值来自当前佩戴条件，换人或电极位置变化后应重新校准。
- GY 轴的选择基于当前模块安装方向；改变模块朝向时应重新评估轴向或使用 SW0 取反。
- 当前系统是规则控制，不包含机器学习分类器。
