# 可复用技能包

本目录把项目开发中形成的验证方法整理成可复用技能，不绑定具体机械臂题目。

## 技能列表

| 技能 | 适用场景 | 使用方法 | 失效条件 | 已验证效果 |
| --- | --- | --- | --- | --- |
| `vivado-clean-build` | 使用 Tcl 构建的 Vivado RTL 工程 | 先运行 `check_repo.py`，再依次创建工程、仿真和构建 | 工程依赖仓库外文件、器件型号缺失或工具版本不兼容 | 从空目录创建 Vivado 2025.1 工程，三组仿真 PASS，综合实现 0 error |
| `uart-telemetry-check` | 固定帧头、固定长度和异或校验的二进制 UART 协议 | 输入一帧十六进制数据，检查长度、校验和字段 | 帧长度、帧头或校验算法不同 | 正确解析本项目 18 字节帧，并识别帧长和校验错误 |

## 复用原则

- 先阅读各技能目录中的 `README.md`。
- 只复用流程和检查方法，不假定其他项目使用相同引脚或阈值。
- 修改帧格式、时钟频率或工具版本后，必须重新验证。
